# Reproduction plan and acceptance gates

The selected target is `unroll714_sew` z24/Ncol. Run the complete chain on
Modal and keep local checks small. A new training run may have different GPU
checkpoint bytes; success requires the same verified inputs and configuration,
plus simulated-300 and sea-64 metrics within the fixed limits: mean five-gas
RMSE difference at most 0.001 dex and temperature/skin-temperature RMSE
differences at most 0.05 K each. The [baseline gate](baseline_gate.md) tracks
numerical agreement separately from historical file identity.
